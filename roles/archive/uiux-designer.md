# UI/UX Designer

## The Role

We're looking for a UI/UX Designer to improve the user experience of our device management dashboard. You'll design interfaces for monitoring router fleets, visualising network data, and managing distributed infrastructure - making complex technical information accessible and actionable.

## What You'll Do

- Design intuitive interfaces for device fleet management
- Create data visualisation designs for network metrics and signal strength
- Design map-based interfaces for geographic device tracking
- Improve dashboard layouts for real-time monitoring
- Design mobile-responsive interfaces
- Create design system components using Tailwind CSS
- Conduct user research with network operations teams
- Prototype and iterate on complex data displays

## Required Skills

- UI/UX design experience (3+ years)
- Data visualisation and dashboard design
- Design tools (Figma, Sketch, or similar)
- Understanding of responsive design principles
- Experience with design systems
- Ability to work with technical stakeholders

## Technical Knowledge

- Basic understanding of React component architecture
- Tailwind CSS or utility-first CSS frameworks
- Charting libraries (Recharts, D3 concepts)
- Map interfaces (Leaflet, Mapbox)
- Real-time data display patterns
- Accessibility standards (WCAG)

## Portfolio Should Demonstrate

- Dashboard and data visualisation designs
- Complex information architecture
- Technical/enterprise software interfaces
- Design system documentation
- Before/after improvement case studies

## Nice to Have

- Experience with network monitoring tools
- IoT or industrial interface design
- Geographic/mapping interface experience
- Frontend development skills (HTML, CSS, JavaScript)
- Experience designing for operations/NOC teams

## How we work

### High ownership

Every team member owns their work end to end. Accountability from first thought through shipped, deployed, and monitored - no throw-it-over-the-wall.

### Resourcefulness

Small teams solve problems by being creative with what's in front of them. The best fix is often the one you can start today with the tools already on your bench.

### Collaboration

We work in the open. Anyone can review anyone's code, every decision is discussable, and we combine backgrounds - networking, embedded, cloud, front-end - because that's what the stack needs.

### Excellence

We hold high standards for what we ship. Our customers rely on connectivity that has to work - "try again later" isn't an option on a live broadcast or a moving vehicle.

### Innovation

Bonded 4G/5G is a demanding field with a small number of serious players. Staying ahead means constantly pushing what's possible - new hardware, better bonding, tighter operational insight. If you like frontier work, this is that.
