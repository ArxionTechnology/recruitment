# DevOps / Platform Engineer

## The Role

We need a DevOps Engineer to build and maintain the infrastructure that powers our distributed device fleet. You'll work with containerisation, service mesh technologies, secrets management, and CI/CD automation across cloud and edge environments.

## What You'll Do

- Design and maintain Docker-based deployment pipelines
- Manage HashiCorp stack (Vault for secrets, Consul for service discovery)
- Build and maintain Terraform providers and infrastructure-as-code
- Implement security scanning and SBOM generation in CI/CD
- Configure and maintain InfluxDB for metrics and time-series data
- Manage TLS/mTLS certificate infrastructure and PKI
- Monitor system health and implement alerting
- Optimise container images and deployment workflows

## Required Skills

- Strong Docker experience (multi-stage builds, compose, orchestration)
- HashiCorp ecosystem (Vault, Consul, Terraform) - 2+ years
- CI/CD pipelines (GitHub Actions preferred)
- Linux system administration (Alpine, Debian)
- Shell scripting (Bash)
- Infrastructure-as-Code principles
- TLS/SSL certificate management

## Technical Knowledge

- Go programming (for tooling and Terraform providers)
- PostgreSQL administration
- MinIO/S3 object storage
- Process supervision (runit, systemd)
- Network configuration and VPN technologies
- Container security scanning (Trivy)
- Metrics and monitoring (Telegraf, InfluxDB)

## Nice to Have

- Kubernetes experience
- Experience with edge computing deployments
- GoReleaser for release automation
- Plugin development (Vault database plugins)
- Network security and firewall configuration
- Experience managing distributed IoT/router fleets
