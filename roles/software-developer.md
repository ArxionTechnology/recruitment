# Software Developer (Backend/Full-Stack)

If you can do the majority of the below, and learn the rest, we want to hear from you! Don't be put off if you don't tick all the boxes!

## The Role

We're looking for a Software Developer to help build and extend our device management platform. You'll work on Go microservices, REST APIs, real-time event systems, and React frontends that monitor and control distributed network infrastructure.

## What You'll Do

- Design and implement RESTful APIs in Go using the Gin framework
- Build and maintain PostgreSQL database schemas
- Develop real-time features using Server-Sent Events (SSE)
- Implement secure authentication flows (JWT, mTLS, certificate validation)
- Create React components for device monitoring dashboards
- Write integration tests and maintain CI/CD pipelines
- Collaborate on architecture decisions for distributed systems
- Architect, design, implement and extend business-critical internal tooling

## Required Skills

**Backend (Primary)**
- Strong Go experience (3+ years)
- RESTful API design and implementation
- PostgreSQL and ORM frameworks (GORM preferred)
- Understanding of concurrent programming (goroutines, channels, mutexes)
- Docker containerisation and multi-stage builds

**Frontend**
- React with hooks (useState, useCallback, useMemo)
- Modern JavaScript (ES6+, async/await)
- CSS frameworks (Tailwind CSS preferred)
- HTTP clients and API integration (Axios)

## Nice to Have

- Experience with mTLS and X.509 certificate handling
- Knowledge of HashiCorp tools (Vault, Consul, Terraform)
- Time-series databases (InfluxDB)
- Real-time protocols (SSE, WebSockets)
- Network protocols and embedded systems exposure
- Data visualisation libraries (Recharts, D3)

## What We Offer

- Work on interesting distributed systems challenges
- Modern tech stack with latest tooling
- Flexible working arrangements
- Opportunity to shape product direction

## How we work

### High ownership

Every team member owns their work end to end. Accountability from first thought through shipped, deployed, and monitored - no throw-it-over-the-wall.

### Resourcefulness

Small teams solve problems by being creative with what's in front of them. The best fix is often the one you can start today with the tools already on your bench.

### Collaboration

We work in the open. Anyone can review anyone's code, every decision is discussable, and we combine backgrounds - networking, embedded, cloud, front-end - because that's what the stack needs.

### Excellence

We hold high standards for what we ship. Our customers rely on connectivity that has to work - "try again later" isn't an option on a live broadcast or a moving vehicle.
